# Security Best Practices

- Use HTTPS everywhere (enforce in production).
- Use strong password hashing (bcrypt).
- Validate and sanitize all user input.
- Use helmet for secure HTTP headers.
- Implement CORS with a whitelist.
- Rate limit all endpoints.
- Store secrets securely (never in code).
- Regularly audit dependencies and code.
- Enable logging and monitoring for suspicious activity.
- Enforce KYC/AML for all users.
