# Legal and Security Documentation - WN Casino P2P

## Legality
- Compliance with local and international regulations on gambling and cryptocurrencies.
- Implementation of AML/KYC processes for user verification.
- Clear terms and conditions for users.
- Privacy policy and data protection.

## Security
- Regular code audits and penetration testing.
- Encryption for all communications (HTTPS/TLS).
- Secure management of keys and Bitcoin wallets.
- Audit logs and monitoring of suspicious activities.
