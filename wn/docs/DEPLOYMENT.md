# Deployment Guide

## Prerequisites
- Node.js and npm installed
- AWS account (for secrets and hosting)
- Production database (e.g., MongoDB Atlas)

## Steps
1. Clone the repository
2. Install dependencies: `npm install`
3. Set environment variables (see [Environment Variables](./ENVIRONMENT.md))
4. Deploy backend and frontend (e.g., AWS EC2, Vercel, Netlify)
5. Set up CI/CD (see [CI/CD Pipeline](./CI_CD.md))
6. Monitor logs and security alerts
